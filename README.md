# eaticWeb
This project reflects my ability to move beyond design and build real, responsive web experiences from scratch.

A responsive multi-page front-end project converted from my own Figma design into a real website as part of practical training in a company environment.

## About The Project

**eaticWeb** is a front-end landing page project that started as a UI design created by me in **Figma**, then was transformed into a fully implemented website.

This project highlights my ability to bridge the gap between **UI/UX design** and **front-end development** by turning a design concept into a real, responsive, and structured user experience.

It was developed during a **practical training experience in a company**, where the focus was on writing clean code, maintaining layout accuracy, creating reusable sections, and ensuring responsiveness across different screen sizes.

## Technical Notes

- The project was originally designed by me in **Figma**
- It was implemented as a real front-end project during company training
- The project is **not built using JavaScript frameworks** such as React or Vue
- **Bootstrap** was used to support layout structure, responsiveness, and faster UI implementation
- The focus was on building a production-like front-end structure using core web technologies
